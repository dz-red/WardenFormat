# WardenFormat
Форматирование названий предметов через `&`-коды в наковальне (Paper). Переименовываешь предмет с цветовыми кодами (`&a`, `&l` …) — они применяются.

## Возможности
- `&`-коды цвета/стиля в названиях предметов через наковальню
- Права на использование

## Сборка
`mvn clean package` (JDK 21)

## Стек
`Java 21` · `Paper API` · `Maven`
